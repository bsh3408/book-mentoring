# 독서멘토링 · SF 과학검증 + 바이브코딩

SF 소설 속 과학 설정을 **비판적으로 검증**하고, 그 결과를 **인터랙티브 웹앱**과 **1인 1웹페이지 독후감**으로 만드는 10차시 독서멘토링 프로그램의 수업 자료입니다.

## 교육 목표
- SF 소설 속 과학을 논문·과학 매체로 팩트체크하며 **과학적 사고력·정보 리터러시** 강화
- 검증한 과학 개념을 시각화하며 **과학·공학·정보 융합 진로 탐색**
- **바이브코딩**(생성형 AI 협업 코딩)으로 자기주도적 산출물 제작

## 차시 구성
1. 오리엔테이션 · 도서 선정 · 바이브코딩 시연
2. 1차 독서 · 과학 요소 메모법
3. 중간 점검 · 자료조사법 · (프론트/백엔드·프롬프트 기초)
4. 사실 검증 · 팩트체크 · 핵심 주제 선정
5. 웹앱 기획
6–7. 바이브코딩 실습
8. 독후감 웹페이지 제작
9. 다듬기 · 1:1 피드백
10. 결과 공유회

## 폴더 구성
- `00_공통자료/` — 생기부 연계 협조요청 안내문 등
- `01_1주차_…/` — 오리엔테이션·도서선정 (수업안내, 요구파악 설문, 추천도서 리스트, 시연용 웹앱)
- `02_2주차_…/` — 1차 독서·메모법 (책 읽는 법)
- `03_3주차_…/` — 바이브코딩 기초 (프론트/백엔드·프롬프트, 앱스크립트 첫 웹앱 예시)
- `04_4주차_…/` — 사실검증·팩트체크 (헤일메리 검증 모음집·인터랙티브 웹앱)
- `문해력_향상자료/` — 문맥 추론·유추 연습 등

## 산출물 예시
- **인터랙티브 검증 웹앱** — 예) 「마션」 화성 감자농사, 「프로젝트 헤일메리」 생명·연료 검증
- **문해력 훈련 자료** — 문맥 추론(단어 뜻 유추), 통합형

## 만든 자료의 성격
- HTML 파일은 모두 **외부 라이브러리·요청 없이 단독 실행**되며, 반응형·다크모드를 지원합니다.
- hwpx는 한글(HWP) 문서입니다.
