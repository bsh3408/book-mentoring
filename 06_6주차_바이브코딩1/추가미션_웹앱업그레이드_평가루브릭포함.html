독서멘토링 · 6주차 추가 미션

오늘 만든 웹앱, 한 단계 업그레이드하기

오늘 배운 세 가지(AI 검증·물리 충돌·화학 결정화) 중 골라서, 오늘 만든 검증 웹앱에 실제로 심어 보는 미션

🎯 미션 규칙

레벨1은 필수, 레벨2는 두 개 중 하나를 골라 도전, 레벨3은 시간이 남으면 보너스. 다 끝내지 못해도 어디까지 했는지가 평가에 그대로 들어간다.

  • 레벨1(필수) 완료
  • 레벨2(택1) 완료
  • 레벨3(보너스) 도전
  • 마지막에 멘토에게 1분 발표
LEVEL 1 · 필수AI 검증 배지 달기⏱ 20~25분
오늘 워밍업 지문(AI는 어떻게 다음 단어를 예측하는가)의 결론을 웹앱에 직접 구현한다: “AI 말은 그럴듯한 것이지 검증된 사실이 아니다.” 웹앱에서 과학적으로 검증한 내용 옆에 “✓ 검증됨” 배지를, 아직 확인 못 한 내용에는 “⚠ 미검증” 배지를 표시해 보자.
AI에게 이렇게 요청해 보기 — “내 웹앱의 각 검증 카드 옆에 초록색 ‘검증됨’ 배지와 회색 ‘미검증’ 배지를 CSS로 추가해줘. 배지를 누르면 그 근거(출처)가 툴팁으로 뜨게 해줘.”
LEVEL 2 · 택1오늘 배운 과학 개념, 미니 시뮬레이터로 넣기⏱ 30~40분
  • 물리 응용 — 오늘 지문(완전탄성충돌·완전비탄성충돌)을 그대로 시뮬레이터로. 공 2개가 부딪혔을 때 “튕겨 나가기(탄성)”와 “한 덩어리로 뭉치기(비탄성)”를 버튼으로 전환해 보여준다.
    힌트: “속도 슬라이더 2개, 충돌 방식 선택 버튼, 충돌 후 속도를 계산해서 애니메이션으로 보여주는 HTML/JS 만들어줘”
  • 화학 응용 — 오늘 지문(농도↑→결정핵 多→입도 小)을 슬라이더로. 농도 슬라이더를 움직이면 화면에 입자 크기·개수가 실시간으로 바뀌는 미니 시각화.
    힌트: “농도 슬라이더 값에 따라 작은 원(결정핵)의 개수는 늘고 크기는 작아지는 캔버스 애니메이션 만들어줘”
LEVEL 3 · 보너스완성도 다듬기⏱ 남는 시간
다크모드 지원, 모바일 화면 대응, 또는 오늘 웹앱에 내 독후감 한 문단을 넣어 8주차(독후감 웹페이지)를 미리 시작해 보기. 무엇을 골랐는지, 왜 골랐는지 한 줄로 적어 두자.

🗣️ 마무리 · 1분 발표

멘토에게 이렇게 설명해 보자: “오늘 [ 무슨 개념 ]을 검증했고, 그걸 웹앱에 [ 어떻게 ] 구현했어요. 만들면서 AI가 준 코드 중 [ 무엇 ]을 직접 확인해 봤어요.”
이 한 문장이 그대로 생기부용 정리본의 재료가 된다.

📝 평가 루브릭 (멘토용 채점표)

항목당 5점, 총 20점. 상(5)·중(3)·하(1) 기준으로 즉석 채점.

항목상(5)중(3)하(1)점수
① 기능 구현도 레벨1·2를 모두 실제로 작동하게 구현 레벨1은 완성, 레벨2는 시도했으나 일부만 작동 레벨1도 미완성
② 개념 적용 정확성 오늘 지문의 원리(검증·충돌·결정화)를 정확히 반영 개념을 넣긴 했으나 일부 오류나 어색함 있음 개념과 무관하게 구현됨
③ AI 결과 검증 태도 AI가 준 코드·설명을 스스로 확인·수정한 흔적이 뚜렷함 일부는 확인했으나 대부분 그대로 사용 검증 없이 그대로 사용
④ 설명력(발표) 무엇을·어떻게·왜 했는지 스스로 논리 있게 설명 일부는 설명하나 근거가 약함 설명하지 못함
총점 / 20
