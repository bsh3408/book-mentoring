홈페이지는 어떻게 만들어질까?

오늘부터 ‘만들기’가 시작됩니다. 겁먹지 마세요 — 코딩은 AI에게 말로 시킬 거예요. 다만 무엇을 시키는지 알려면, 홈페이지가 어떤 구조인지 비유로 딱 두 가지만 알고 갑시다.

🎯 우리의 최종 목표

나만의 SF 독후감 홈페이지를, 폰에서도 PC에서도 예쁘게 보이는(반응형) 웹앱으로 만들기. 오늘은 그 첫걸음 — 프론트엔드 · 백엔드를 이해하고, AI에게 말 거는 법(프롬프트)으로 홈페이지 첫 화면을 만들어 봅니다.

비유 1 · 웹페이지 = 사람 몸

웹페이지 하나는 ‘무엇으로’ 만들어질까요? 사람 몸에 빗대면 쉽습니다.

🦴
HTML
= 뼈대·골격
제목·버튼·문단이 “여기 있다”는 구조
👕
CSS
= 옷·피부
색·글꼴·배치, 예쁘게 꾸미기
💪
자바스크립트
= 근육·신경
버튼 누르면 반응·계산, 움직임
🧱
React
= 레고 블록
자바스크립트를 조각내 조립·재사용

📖 독후감 홈페이지로 보면 — 줄거리·검증 결과 글의 구조가 HTML(뼈대), 색과 표지 디자인이 CSS(옷), “검증 결과 펼쳐보기” 같은 버튼 반응이 자바스크립트(근육)예요.

비유 2 · 웹앱 = 식당

웹앱은 ‘어떻게 돌아가는지’가 중요해요. 식당에 빗대면 한 방에 이해됩니다.

🍽️
프론트엔드
= 홀 (front)
손님이 보고 만지는 곳 = 화면
👨‍🍳
백엔드
= 주방 (back)
안 보이는 곳에서 실제로 처리
🏪
서버
= 24시간 가게
요청하면 내주는 쪽 (serve = 대접)
🧊
데이터베이스
= 냉장고·창고
재료(데이터)를 보관하는 곳
🍽️
홀 (프론트)
손님이 주문·구경
→
👨‍🍳
주방 (백)
뒤에서 요리·처리
→
🧊
냉장고 (DB)
재료 꺼내고 보관

그래서, 프론트엔드 vs 백엔드

한 문장: 보이면 프론트, 안 보이면 백엔드.

🍽️ 프론트엔드 (홀)

  • 손님(방문자)이 눈으로 보는 모든 것
  • 화면·색·글꼴·버튼·애니메이션
  • 재료: HTML · CSS · 자바스크립트
  • 독후감 홈: 내 독후감 글, 표지, 디자인

👨‍🍳 백엔드 (주방)

  • 손님 눈엔 안 보이지만 뒤에서 일함
  • 저장·계산·불러오기 같은 처리
  • 서버 + 데이터베이스와 함께 작동
  • 독후감 홈: 방명록 저장, 방문자 수 세기

AI에게 말 거는 법 · 프롬프트

‘프롬프트(prompt)’는 AI에게 건네는 주문서예요. 요리사(AI)에게 “이렇게 만들어 주세요” 하고 부탁하는 말이죠. 주문을 잘할수록 원하는 게 정확히 나옵니다.

❌ 막연한 주문

“홈페이지 만들어줘”
→ 뭘 담을지 몰라 엉뚱하게 나옴

✅ 좋은 주문

“「마션」 독후감 홈페이지 만들어줘. 맨 위 큰 제목, 줄거리 3줄, ‘내가 검증한 과학’ 3개(누르면 펼쳐짐), 마지막에 소감. 화성 느낌의 어두운 배경, 폰에서도 잘 보이게.”

좋은 프롬프트의 4가지 재료

📦
① 무엇을 · 무엇을 담아
“독후감 홈페이지. 제목·줄거리·검증·소감 넣어줘”
🎨
② 느낌 · 디자인
“우주 느낌 어두운 배경, 파란 강조색으로”
🖱️
③ 기능
“검증 결과는 눌러서 펼쳐지게, 반응형으로”
🔁
④ 고쳐 말하기
“글씨가 작아, 크게”, “표지 넣을 자리 만들어”

🖐 오늘 실습 · AI와 대화하며 내 홈페이지 첫 화면 만들기

  1. 내 책으로 위 ‘좋은 주문’처럼 프롬프트를 한 문장 써 본다.
  2. AI에게 보내고, 나온 화면을 눈으로 확인한다.
  3. 맘에 안 드는 곳을 고쳐 말한다 (④번처럼) — 두세 번 반복!
  4. “폰에서도 잘 보이게 반응형으로”를 꼭 한 번 넣는다.

💡 비법은 하나 — 잘하는 사람은 ‘한 번에’ 만드는 게 아니라 여러 번 고쳐 말하며 다듬습니다. 틀려도, 이상하게 나와도 괜찮아요. 그냥 “이렇게 바꿔줘” 하면 됩니다. 마음껏 시켜 보세요!
